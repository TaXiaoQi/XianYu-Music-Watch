## 1. 软件概述

弦予音乐腕上版软件（以下简称"本软件"）是运行于 HarmonyOS 智能手表的音乐播放与管理软件，是"弦予音乐"系列在腕上设备的产品形态。本软件针对圆形表盘屏幕、表冠旋转输入与低功耗使用场景专门设计，提供以下两大工作模式：

- **控制模式**：手表作为手机端弦予音乐的延伸控制器，通过蓝牙直连或云端中继远程控制手机播放；
- **本地模式**：手表独立运行完整播放引擎，直接扫描、播放手表本地存储的音乐文件。

主要功能包括：蓝牙设备配对与自动重连、远程播放控制、表冠音量调节、本地音乐扫描与播放、逐字歌词显示、均衡器音效调节、收藏与歌单管理、每日推荐、插件化在线音源、收听统计与设置同步。

### 1.1 运行环境

| 项目 | 要求 |
|---|---|
| 设备 | 华为 WATCH 5 系列或搭载 HarmonyOS 5.1.0 及以上（Wearable API 18+）的智能手表 |
| 内存 | 2GB 及以上 |
| 存储 | 建议预留 100MB 以上应用与数据空间 |
| 配套设备（控制模式） | 安装弦予音乐移动版的手机（Android / 鸿蒙） |

### 1.2 安装与启动

本软件通过华为应用市场或开发者侧载方式安装到手表。首次启动时，软件检测当前使用场景并请求进入相应模式：

- 手表与手机已配对且手机端正在运行弦予音乐 → 建议进入**控制模式**；
- 手表已存有本地音乐文件或需要独立使用 → 可切换至**本地模式**。

两种模式可随时在主页切换，切换后各自保留独立状态。

## 2. 控制模式：手表遥控手机播放

### 2.1 设备配对与连接

在控制模式首页，软件按以下优先级自动建立与手机的链路：

1. **蓝牙直连**：手机端弦予音乐开启"手表连接"后，手表通过蓝牙 RFCOMM 通道自动发现并连接已配对的手机，全程无需手动输入；
2. **云端中继**：当蓝牙不可用（超出距离、手机后台受限）时，若用户已登录弦予账号，自动通过云端加密中继保持控制链路；
3. **自动重连**：链路中断后软件按退避策略自动重连，并设置连接看门狗防止无效等待。

连接成功后，首页显示当前连接设备名称与链路类型（蓝牙 / 云端）。

### 2.2 远程播放控制

连接建立后，手表页面实时显示手机端正在播放的歌曲，支持以下操作：

- 播放 / 暂停 / 上一曲 / 下一曲；
- 播放进度显示与拖动定位；
- **表冠音量调节**：旋转表冠直接调节手机播放音量，页面同步显示音量刻度；
- 歌曲收藏快捷操作。

### 2.3 设备管理

在连接管理页可查看历史配对设备列表、当前链路状态，并可手动断开或切换目标设备。开启"自动连接"后，软件在检测到已配对手机时自动恢复链路。

## 3. 本地模式：手表独立播放

### 3.1 本地音乐扫描

进入本地模式后，软件申请存储读取权限，自动扫描手表本地存储中的音频文件，按歌曲、歌手、专辑归类展示。扫描设置中可自定义扫描目录与文件格式过滤。

### 3.2 音乐播放

在歌曲列表点按即可播放。播放页针对圆形屏幕设计：

- 封面背景随歌曲动态呈现；
- 边缘滑动切换播放页与歌词页；
- **表冠旋转调节音量**，点按表冠为播放/暂停快捷键；
- 支持后台播放与屏幕常亮设置。

### 3.3 收藏与歌单

播放中可将歌曲加入收藏；收藏页与自建歌单统一管理，支持排序与批量操作，数据与手机端同步。

## 4. 逐字歌词

本地模式播放支持逐字歌词渲染：歌词按字符级时间戳高亮当前演唱位置，提供歌词页独立视图，圆屏边缘滑动即可呼出。歌词数据可随歌曲文件内嵌或通过网络获取。

---

## 5. 音效调节

音效页内置均衡器（EQ）与预设音效方案：

- 多段均衡器独立调节各频段增益；
- 预设方案一键切换（流行、古典、人声等）；
- 音效设置即时生效并持久保存。

## 8. 常见问题

**Q1：手表无法连接手机？**
确认手机端弦予音乐已启动且开启"手表连接"；确认两端蓝牙已开启且已配对；若手机长时间灭屏，部分系统会限制后台网络，点亮手机屏幕后重试；蓝牙持续不可用时软件将自动切换云端中继。

**Q2：本地模式扫描不到歌曲？**
确认存储权限已授予；确认音频文件位于扫描目录内且为受支持格式（MP3 / FLAC / WAV / M4A 等）。

**Q3：控制模式下操作无响应？**
链路可能已中断，返回连接页查看状态；软件会自动重连，也可下拉手动重连。

**Q4：耗电快怎么办？**
建议在设置中关闭"屏幕常亮"；控制模式下软件已内置省电策略（心跳超时判死、退避重连），长时间不用可直接退出应用。
